# UI Content Guidelines

Use operational language.

Prefer:

- `Station operational`
- `Last synchronized 2 min ago`
- `3 assets require attention`
- `Fuel reserve: 18.6 days`
- `Energy demand forecast`
- `Generator temperature anomaly`
- `Simulation result`
- `Data source: Simulated`

Avoid:

- `AI Magic`
- `Unlock insights`
- `Revolutionize operations`
- `Your intelligent future`
- `Powered by AI`
- `Amazing insights`
- marketing filler

The interface should feel like software used by trained operators.
